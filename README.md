# 🕴️ 하늘 위로!

> 안경 쓴 치비 캐릭터가 하늘을 향해 도약! 발판을 밟고 새를 피하며 최고 높이에 도전!

**▶ 지금 바로 플레이** → [https://mindweaver74.github.io/jumpman](https://mindweaver74.github.io/jumpman)

---

## 🎮 게임 방법

1. 발판을 밟으면 캐릭터가 자동으로 튀어오릅니다
2. 좌우 버튼 또는 방향키로 이동하며 더 높은 발판으로 올라가세요
3. 날아다니는 새를 피하세요 — 맞으면 아래로 튕겨집니다!
4. 바닥으로 떨어지면 게임 오버
5. 최대한 높이 올라가 최고 기록에 도전하세요!
6. 모은 코인으로 시작 화면에서 업그레이드!

## 🐦 방해물 — 새

- 100m 이상부터 새가 등장합니다
- 화면 좌우를 왔다갔다하며 방해합니다
- 높이 올라갈수록 더 많은 새가 등장합니다 (최대 4마리)

| 충돌 방향 | 결과 |
|----------|------|
| ⬇️ 위에서 밟기 | 새 처치 + 위로 튀어오름 + 🐦 +50점 |
| ➡️ 옆에서 부딪히기 | 😵 앗! + 아래로 튕김 |

> 새를 연속으로 밟으면 발판 없이도 계속 위로 올라갈 수 있어요!

---

## 🌤️ 배경 변화

높이에 따라 배경이 변화합니다:

```
0m~400m   → 맑은 낮 하늘 + 흰 구름
400m~800m → 저녁노을빛 하늘
800m+     → 밤하늘 + 별빛 등장
```

## 🔧 업그레이드 시스템

게임 시작 화면에서 **🔧 업그레이드** 버튼을 눌러 코인으로 능력치를 강화하세요!

| 업그레이드 | 효과 | 최대 레벨 | 비용 |
|-----------|------|---------|------|
| 🦘 점프력 | 점프 높이 증가 | 3레벨 | 🪙30→60→100 |
| 👟 이동 속도 | 좌우 이동 속도 증가 | 3레벨 | 🪙25→50→80 |
| 🧲 코인 자석 | 코인 흡수 범위 확대 | 3레벨 | 🪙20→40→70 |
| 🛡️ 새 방어막 | 새 충돌 쿨타임 단축 | 2레벨 | 🪙50→90 |
| 🌀 스프링 부스트 | 스프링·슈퍼 점프력 추가 | 2레벨 | 🪙60→100 |

> 코인은 게임 종료 후에도 누적 저장됩니다. 조금씩 쌓아서 업그레이드하세요!

## 💡 공략 팁

- 🟣 보라색 슈퍼 발판을 놓치지 마세요 — 단번에 엄청나게 높이 올라갑니다
- 이동 발판은 끝으로 가기 전에 타이밍을 맞춰 밟으세요
- 새가 화면 끝에서 돌아올 때 타이밍을 보고 지나가세요
- 새를 위에서 밟으면 +50점 + 위로 튀어오릅니다 — 발판처럼 활용하세요!
- 새 연속 밟기로 발판 없이 높이 올라가는 것도 가능합니다
- 부서지는 발판(빨간색)은 한 번 밟으면 바로 사라집니다 — 연속으로 밟지 마세요
